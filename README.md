# Служба доставки

Консольний застосунок на C# (.NET 10), що моделює службу доставки: облік замовлень, вибір транспорту, розрахунок вартості та оплата.

## Можливості

- додавання транспорту та замовлень;
- розрахунок вартості доставки для кожного виду транспорту;
- перевірка, чи може транспорт узяти замовлення;
- призначення замовлення транспорту (зайнятий транспорт не приймається);
- доставка з оплатою карткою або готівкою;
- перегляд активних замовлень та історії доставок.

## ООП-концепції

| Концепція | Де використано |
|---|---|
| Абстракція | абстрактний клас `Transport` |
| Наслідування | `Bike`, `Car`, `Truck` → `Transport` |
| Поліморфізм | перевизначення `CalculateCost` та `CanTake` |
| Інтерфейси | `IPaymentMethod` → `CardPayment`, `CashPayment` |
| Інкапсуляція | стан замовлень і транспорту керується через `DeliveryService` |

## Тарифи

| Транспорт | Вартість, грн | Обмеження |
|---|---|---|
| Велосипед | `20 + 5 × відстань` | відстань ≤ 10 км |
| Авто | `50 + 8 × відстань + вага` | — |
| Вантажівка | `200 + 15 × відстань + 0.5 × вага` | — |

Для всіх видів транспорту вага та відстань мають бути більшими за 0.

## Структура

```
.
├── Module1.csproj
├── Program.cs               # точка входу, демонстраційний сценарій
├── Models/
│   └── Order.cs             # замовлення
├── Payments/
│   ├── IPaymentMethod.cs    # інтерфейс оплати
│   ├── CardPayment.cs
│   └── CashPayment.cs
├── Transports/
│   ├── Transport.cs         # абстрактний базовий клас
│   ├── Bike.cs
│   ├── Car.cs
│   └── Truck.cs
└── Services/
    └── DeliveryService.cs   # логіка служби доставки
```

## Запуск

Потрібен [.NET SDK 10.0](https://dotnet.microsoft.com/download).

```bash
dotnet run
```
